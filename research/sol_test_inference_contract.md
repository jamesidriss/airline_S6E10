# Frozen route/auxiliary10 test policy

Declared before the full699635-row context resource probe and before any
candidate test vector or new public score exists. The only method weights are
route0.5 and equal-logit auxiliary10 collectively0.5. No score-based weight grid.

The primary test policy uses all competition training labels: TabPFN takes the
entire training context with the exact pretrained checkpoint, representation,
seed1201 and inference settings. Each classical role refits its identical
estimator configuration at the fixed median of its five primary selected tree
counts. Test feature construction uses the same three-inner-fold auxiliary
rating recipe and strict own-label-free target-encoding priors. No test target
or leaderboard score enters any transform or capacity decision.

First run the resource-only full-context probe on1024 test covariates, reporting
no performance score. A resource refusal is not negative model evidence. Any
resource implementation change must preserve every context row and pass the
whole-model100k-context probability gate (maximum gap<=0.000002) before use.
Keep completed primary runner/helper bytes and reports intact. Record new
implementation hashes separately; do not splice materially different arithmetic
into the existing CV claim.

If a full-context implementation remains infeasible, the only predeclared
fallback is probability averaging of five predictions using the five immutable
primary FIT contexts. Each has the same population and recipe as the validated
OOF member. Refit these contexts in fresh processes and retain per-fold test
vectors/IDs/hashes. Explicitly report this as CV-model test averaging, not a
full-data fit. Do not subsample arbitrary smaller contexts or represent a
timing subset as validated full CV. The fallback is a resource policy, not a
weight optimization.

Test inference remains conditional on replicated, complete primary OOF and
its admission gate. A resource probe alone cannot select or submit a finalist.
Final selection also requires independent confirmation, private simulation,
paired bootstrap, OOF/test ranking correlations and pair rescue/damage.
