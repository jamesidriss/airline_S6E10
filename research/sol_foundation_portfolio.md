# Frozen foundation-model portfolio hypotheses

Declared before any own full-context TabPFN CV result exists. This is not a
weight optimization plan. No public score selects a model or changes a weight.

1. Discovery: matched raw/route TabPFN 3.5 controls, one estimator, seed1201,
   immutable primary folds, complete outer-FIT context, no early stopping.
   Computation chunks and selective ICL bf16 are resource settings. The input
   preprocessing remains fp32, including exact route-category codes.
2. Expected-performance comparison: append the frozen route member at weight
   1/60 to the 59-member legacy-v5 OOF reference. Promotion uses the established
   paired fold gate. Legacy v5 is a comparison vector, not a clean reproduction.
3. Hedge hypothesis: first evaluate the pure route model if it is within0.0003
   of the strongest candidate. If it is too weak alone, evaluate ONE fixed
   50/50 mean-logit combination of route and the ten corrected auxiliary
   counterparts. Equal method votes give the new architecture material influence.
   No 10/20/30/... weight sweep, fitted stack or public-score tilting.
4. The ten-member classical component is fixed structurally: the six XT, three
   XGB and one native CatBoost counterparts originally substituted by v5. All
   their competition-label encoders must use the corrected inner priors.
5. Any finalist needs complete primary OOF, test refit, prediction/ID hashes,
   test rank correlations, pair rescue/damage, private simulation and independent
   confirmation. A half-trained candidate or legacy mixture is not admitted.

The 50/50 hypothesis can be falsified by an OOF gap >0.0003, collapsed test
diversity, adverse private-simulation tails, or contradicting shadow evidence.
Resource-invalid probes are not negative model evidence.
